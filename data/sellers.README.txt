 Format: { "sellers": [ { "id": "s1", "name": "Ism", "pin": "1234", "role": "seller|admin" } ] }

 - role: "seller"  → бронирует и продаёт, освобождает только свои записи
 - role: "admin"   → видит журнал операций, освобождает и проданные места
 - Имя используется и для входа (в окне входа можно ввести имя или ID)
