Bu fayl (data/sellers.json) git'ga tushmaydi — PIN'lar shu yerda saqlanadi.

 Format: { "sellers": [ { "id": "s1", "name": "Ism", "pin": "1234", "role": "seller|admin" } ] }

 - role: "seller"  → bron qiladi/sotadi, faqat o'z yozuvini bo'shata oladi
 - role: "admin"   → jurnalni ko'radi, sotilgan joyni ham bo'shata oladi
 - Ism login uchun ham ishlatiladi (kirish oynasida ism yoki ID yoziladi)

Hozirgi demo PIN'lar: Aziz 1111, Dilnoza 2222, Sardor 3333, Menejer 9999.
Ishga tushirishdan OLDIN haqiqiy PIN'larga almashtiring.
