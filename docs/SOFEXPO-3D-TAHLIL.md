## Факты о туре и площадке

| Fakt | Qiymat |
|---|---|
| Экспо | **SOF EXPO SAMARKAND** (Джамбайский район, Самарканд) |
| Даты FOODERA EXPO 2026 | **20–22 октября 2026** (баннер «BOOK A STAND» на сайте) |
| Площадь крытого павильона | **> 4 500 м²** (в нашей схеме 96 × 50 = 4 800 м²) |

## Структура реальной схемы (с прочитанными номерами ячеек)

- **7 колонн: A B C D E F G** (каждая из 2 подколонок). Цвета: A — жёлтый,
  B — синий, C — красный, D — бирюзовый, E — зелёный, F — фиолетовый, G — голубой.
- Ячейки **9 м²** и **12 м²** (в нижних рядах), часть — **18 м²**; прочитанные ID:
  `A5…A10`, `A13…A15`, `B1…B3`, `B8…B12`, `C5`, `C6`, `C12…C20`, `E…`, `F4…F13`, `G5…G20`.
  (Точный список берётся с крупной схемы — см. раздел «Какие файлы нужны» ниже.)
- **Справа 3 больших стенда: `G9/72 м²`, `G10/72 м²`, `G11/72 м²`.**
- **Левое крыло (помещения вдоль стены): A1–A6** = 27,41 · 26,23 · 25,4 · 22,67 · 20,32 · 19,15 м².
  Между A3 и A2 — **«Выход к открытому павильону»**, выше — **«Техническая комната»**.
- **Правая часть (сверху вниз):** Техническая комната · **ГРУЗОВЫЕ ВОРОТА (L GATE, W‑5,6 m H‑5 m)** ·
  **B2B** ×3 · **Hall** · **Переговорная** · **WC** (pastda).
- **Pastda:** **РЕГИСТРАЦИЯ** (ro'yxatga olish, oldida kirish strelkalari) · **BOOKED** (ko'k quti) ·
  **ГЛАВНЫЙ ВХОД** (soyabon) · chap tomonda **WC**, ochiq pavilyonga chiqish yo'lagi.
- По всему залу **конструктивные колонны** (маленькие чёрные квадраты) — их нужно показать на карте.

## Отличия от текущей карты

| | Hozir (`layout/foodera-2026.json`) | Real sxema (`sofexpo`) |
|---|---|---|
| Структура | 18 блоков **A–R** (каждый по шаблону 72 м²) + линия EQ + левое крыло | **Колонны A–G** (по 2 подколонки) + нижние ряды |
| Stend o'lchamlari | hammasi 9 m² (12/18/36/40 m² → 9 m² kataklarga keltirilgan) | 9 · 12 · 18 · **72 m²** aralash |
| Katak raqamlari | ketma-ket (A‑01 … A‑08) | sxemadagi haqiqiy raqamlar (A5, B12, G9 …) |
| Правая часть | Зона B2B / Conference-Hall | 3 стенда × 72 м² + B2B ×3 + Hall + переговорная + грузовые ворота |

То есть **геометрию и нумерацию нужно перестроить по реальной схеме** — после этого карта станет
точной: у каждого стенда будет свой ID и своя площадь.

## Reja (qanday qilaman)

1. **`layout/sofexpo-2026.json`** — новая схема по реальной схеме зала: колонны A–G (по 2 подколонки),
   нижние ряды, 3 стенда × 72 м², левое крыло A1–A6, все зоны (WC, регистрация, B2B, Hall,
   переговорная, грузовые ворота, колонны) и **реальные ID стендов**.
2. Ustun/fon ranglari sxemadagidek (A sariq, B ko'k, C qizil, D feruza, E yashil, F binafsha, G ko'k).
3. Привязать компании FOODERA к **реальным стендам** (по списку компания ↔ ID стенда).
4. Panel, `01-план-зала-весь.pdf`, bo'lim varaqlari, CSV'lar — hammasi yangi layoutdan
   собирается автоматически. Валидатор проверяет правила 9 м²/72 м² и проходы.
5. Сверяем результат вместе с вами: каждый стенд — ID + площадь + компания.

## Какие файлы нужны (для точности)

1. **Interaktiv plan / katta o'lchamdagi sxema** — turdagi «Интерактивный план» rasmi yoki
   `sofexpo.uz` dagi «Indoor pavilion layout» (222.png) **katta** varianti (PDF/DWG/PNG).
2. **PDF «Каталог»** из тура (кнопка «Каталог» на странице тура, `&t=pdf`) — каталог стендов.
3. **Список компания ↔ стенд по FOODERA** (Excel или крупная схема) — покажет, на каком реальном
   ID стоит каждая из 43 компаний.

Fayl bo'lmasa ham 1–2-qadamni boshlash mumkin: geometriyani sxemadan o'lchab quraman, ID'larni
вписываю по прочитанным данным, вы правите.
